# 🛰️ Satellite Tracker

A real-time satellite tracking web app built with React, Express and GraphQL. This project pin points satellite positions using geospatial data and offers a responsive UI for exploring orbital paths and metadata.

## 🚀 Features

- Live satellite location updates via N2YO API
- Smooth rendering of large satellite lists using `react-window`
- Interactive map with custom markers and popups
- Backend routing for satellite data and API proxying

## 🛠️ Tech Stack

- **Frontend:** React, Resium, react-window
- **Backend:** Node.js, Express, GraphQL
- **Data Sources:** N2YO API and Celestrak (static JSON fallback)
- **Map Rendering:** Cesium for react (Resium)

## 📦 Setup Instructions

1. **Clone the repo**
   - git clone https://github.com/EvanClevenger/Satellite-Tracker.git
   - cd Satellite-Tracker
   - npm install
   - Then run server, cd server , npm run start
   - Then run client, cd into root, npm run start
